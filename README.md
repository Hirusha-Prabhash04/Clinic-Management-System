# Clinic-Management-System
A web-based clinic management system for managing patients, appointments, and medicine stock — built with HTML, CSS, and JavaScript.

## Project Structure
- index.html — main homepage
- css/ — stylesheets
- js/ — JavaScript files
- pages/ — feature pages for dashboard, patients, appointments, medicines, billing, and doctors
- assets/ — images and static resources

## Included Pages
- Dashboard — overview stats
- Patients — add, view, and search patients
- Appointments — book, view, and cancel appointments
- Medicines — stock tracker
- Billing — simple bill generation
- Doctors — doctor management placeholder
